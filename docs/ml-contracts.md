# ML Contracts

Owner: designated ML and data team member.

For each model, document:
- Model name and version
- Dataset source and license
- Preprocessing steps
- Input schema and output schema
- Training/validation split
- Evaluation metrics and limitations
- Model artifact location
- Inference function or API interface

Do not claim food is safe based only on an image model.
Keep large datasets and model artifacts out of Git unless specifically approved.
