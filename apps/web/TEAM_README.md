## Responsibilities
- Operations dashboard and navigation
- Inventory and production forms
- Surplus review and food verification workflow
- Recipient and delivery views

Build screens using mock data until backend endpoints are documented and available.
Keep API calls in src/lib or feature-specific API modules.
Do not place secrets in NEXT_PUBLIC variables.
