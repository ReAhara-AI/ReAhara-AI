# Logistics — Owner: Pallavi

## Matching
Match eligible surplus batches with active recipients using capacity, location,
food requirements and time constraints.

## Routing
Develop time-aware delivery route optimization. Keep route inputs and outputs
independent of the API transport layer so the backend can call them.

Use test data for development. Record assumptions and handle infeasible routes.
Food eligibility must be established by the verification workflow, not routing.
